# XMB Wave Studio 사용법

PSP·PS3 웨이브를 편집하고 JPEG 이미지와 반복 MP4 영상을 만드는 로컬 도구.

## 최초 설치

Windows x64, Python 3.12 이상, WebGL2와 하드웨어 가속을 지원하는 Edge 또는 Chrome이 필요하다. 기준 개발 환경은 Python 3.12다.

프로젝트 폴더에서 PowerShell로 실행한다. 가상환경 활성화는 필요 없다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e . --no-deps
```

초기 설치에는 인터넷이 필요하다. FFmpeg는 Python 패키지에 포함되어 별도 설치하지 않아도 된다. 실행에 필요한 Three.js도 프로젝트에 포함되어 있다. 이후 편집·이미지 저장·영상 제작에는 인터넷이 필요 없다.

## 실행과 종료

```powershell
.\.venv\Scripts\python.exe -m xmbwavestudio
```

가상환경을 활성화한 경우 `python -m xmbwavestudio`로도 실행할 수 있다. Windows에서는 `start.bat`를 더블클릭해도 된다. EXE 패키징은 포함하지 않는다.

서버가 준비되면 기본 브라우저에서 `http://127.0.0.1:8765`를 연다. 기본 브라우저가 다른 제품이면 이 주소를 Edge 또는 Chrome에서 직접 열면 된다. 서버는 이 PC의 루프백 주소에만 연결한다.

종료하려면 서버 터미널에서 `Ctrl+C`. 진행 중인 FFmpeg 프로세스와 서버 임시 폴더를 정리한다. 완성 파일도 서버 종료 시 임시 폴더에서 삭제되므로 먼저 다운로드한다. 사용자가 내려받은 파일은 삭제하지 않는다.

### 실행 옵션

| 옵션 | 기본값 | 동작 |
|---|---|---|
| `--port PORT` | `8765` | 1~65535 범위의 로컬 포트 지정 |
| `--no-browser` | 꺼짐 | 브라우저 자동 실행 생략 |
| `-h`, `--help` | — | 도움말 표시 후 종료 |

```powershell
.\.venv\Scripts\python.exe -m xmbwavestudio --port 8766
.\.venv\Scripts\python.exe -m xmbwavestudio --no-browser
```

포트가 이미 사용 중이면 서버를 시작하지 않고 다른 포트를 안내한다. 브라우저 설정 복원은 주소별로 저장되므로 포트가 달라지면 마지막 편집 상태도 별도로 보관된다. 인터랙티브 콘솔 명령과 하위 명령은 없다.

## 편집

1. 오른쪽에서 PSP Classic, PSP Original, PS3 Wave 중 선택한다.
2. 팔레트, 색상 선택기 또는 HEX 코드로 기본 색을 고른다. 배경·물결·빛의 색은 스타일에 맞게 함께 변한다.
3. 웨이브 속도와 회전을 조절한다. 회전은 해상도의 가로·세로 전환과 별개다.
4. PS3 스타일에서는 파티클 개수·크기·이동 속도를 따로 조절한다. 개수 0은 파티클을 끈다. 크기는 0.25~4배이며 해상도가 달라져도 화면에 대한 비율을 유지한다.
5. 고급 조절에서 물결 높이·폭·겹침·전체 크기·가로/세로 위치·빛 강도를 바꿀 수 있다. 배경과 물결 색을 따로 지정할 수도 있다.
6. 하단에서 기기 해상도 프리셋이나 사용자 지정 크기를 선택한다.

기본값은 PS3, 파란색, 1080×1920, 10초, 30fps. 마지막 편집 설정은 같은 브라우저에 자동 보관한다. 스타일을 바꿀 때는 색·회전·배치를 유지하고 물결 형태는 해당 스타일 기본값을 사용한다. 고급 조절의 초기화 버튼은 현재 스타일 설정 전체를 기본값으로 되돌린다.

PS3 입자는 작고 선명한 빛점과 크게 퍼지는 흐릿한 입자를 함께 그린다. 입자마다 초점·밝기·반짝임이 다르며, 대부분 물결 주변을 흐르고 일부는 배경에 흩어진다. 크기 슬라이더는 선명한 입자와 흐릿한 입자의 크기를 함께 바꾸고 개수나 이동 궤적은 바꾸지 않는다. 기본값은 450개, 크기 1배다.

PSP Classic은 화면을 크게 가로지르는 반투명 면과 밝은 경계를, PS3는 폭이 달라지고 서로 교차하는 부드러운 실크층을 그린다. PS3 배경은 하단에도 색을 유지한다. PSP Original은 기존 표현을 유지했다. 기존 설정 그대로 새 렌더링을 사용하며, 변경한 높이·배치 등을 초기화하려면 고급 조절의 초기화 버튼을 누른다. 저장 설정의 기본값 판번호는 2를 유지한다.

PS3 물결은 봉우리와 접힌 부분이 함께 왼쪽에서 오른쪽으로 흐른다. 지정 참고 영상의 이동 속도와 비교하려면 영상 길이를 12초로 설정할 수 있다. 10초에 같은 한 주기를 넣으면 약 20% 빨라지며, 실제 보정 속도는 화면에 표시된다. 선택한 길이를 자동으로 12초로 바꾸지는 않는다.

미리보기는 선택한 화면비를 유지하며 작은 크기로 그린다. 고화질·균형·저사양 옵션은 미리보기만 바꾸며 저장 크기를 바꾸지 않는다. OS의 동작 줄이기 설정이 켜져 있으면 처음에는 일시정지 상태로 시작한다.

## JPEG 저장

원하는 순간에 일시정지하거나 시간 막대를 옮긴 뒤 `JPEG 저장`을 누른다. 재생 중 눌러도 버튼을 누른 시각의 장면을 고정한다.

지정한 정확한 픽셀 크기, 품질 95%, sRGB로 브라우저에서 JPEG를 만든다. UI나 문자, 메뉴는 이미지에 들어가지 않는다.

## MP4 제작

- 길이: 1초 이상의 정수 초. 제품 차원의 상한은 없으며 브라우저가 정확히 계산할 수 있는 정수 범위와 PC의 자원 한도 안에서 처리한다.
- 프레임: 30fps 또는 60fps.
- 형식: MP4 / H.264(libx264) / yuv420p / SDR / 무음.
- 품질: CRF 18, medium 인코딩. 별도 GPU 인코더 설치는 필요 없다.
- 홀수 해상도: 오른쪽 또는 아래 가장자리 픽셀을 반복해 짝수 크기로 1픽셀 확장한다. JPEG 크기는 바꾸지 않는다.

`영상 만들기`를 누르면 출력 크기와 GPU 할당 가능 여부를 확인한 후 제작한다. 제작 중에는 설정 변경을 잠그고 진행률·프레임 수·경과 시간·예상 남은 시간을 표시한다. 완료하면 자동 다운로드하고, `MP4 다운로드` 버튼으로 같은 서버 세션에서 다시 저장할 수 있다. 브라우저가 자동 다운로드를 막으면 해당 버튼을 누르면 된다.

물결과 입자는 지정한 영상 길이마다 제자리로 돌아온다. 이를 위해 요청한 속도를 가장 가까운 반복 주기로 보정하며, 실제 적용 속도를 화면에 표시한다. 짧은 영상에서는 속도 차이가 커질 수 있다. 미리보기도 이 보정을 반영한다. 속도 0은 정지하고 양수 속도는 정지로 보정하지 않는다.

영상 길이가 `T`초, 프레임이 `F`fps이면 `T×F`장의 프레임을 만든다. 마지막에 첫 장면을 중복 삽입하지 않는다. MP4 플레이어 자체의 재시작 지연과 휴대폰 OS의 배경화면 재생 정책은 파일의 반복 처리와 별개다.

### 제작 중 주의할 동작

대시보드 탭과 Python 서버를 열어둔다. 탭을 닫거나 새로고침하면 진행 중인 제작을 중단한다. 창을 최소화하거나 PC를 잠그면 브라우저 정책에 따라 제작이 느려지거나 일시 정지될 수 있지만, 프레임을 건너뛰어 영상 길이를 바꾸지는 않는다.

취소 버튼은 인코더를 종료하고 미완성 파일을 지운다. GPU 손실, 디스크 부족, 인코더 오류도 이유를 표시하고 미완성 파일을 정리한다. 긴 영상 전체를 메모리에 쌓지 않고 작은 전송 청크로 한 프레임씩 처리한다. 최종 파일을 저장할 충분한 디스크 공간은 필요하다.

## 문제 해결

- GPU 초기화 실패: 브라우저 하드웨어 가속을 켜고 최신 Edge·Chrome에서 다시 연다.
- 해상도 오류: 표시된 GPU 한 변 최대 크기와 실제 메모리 할당 가능 범위 안에서 크기를 줄인다. 실패한 크기를 자동으로 축소해서 저장하지 않는다.
- H.264 인코더 없음: `requirements.txt`를 다시 설치한다. 이미지 저장은 인코더가 없어도 사용할 수 있다.
- 디스크 부족: 임시 폴더가 있는 시스템 드라이브에 공간을 확보한다.
- 시작 시 브라우저 미표시: 터미널에 출력된 주소를 직접 연다.

## 개발 검증

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check xmbwavestudio tests
```

별도 터미널에서 서버를 실행한 상태로 실제 브라우저 검증을 실행한다. 기본 검증에는 설치된 Edge와 Chrome을 사용한다.

```powershell
.\.venv\Scripts\python.exe tests/browser_checks.py
.\.venv\Scripts\python.exe tests/browser_checks.py --browser chrome --long
```

`--long`은 32×32, 600초, 30fps 영상을 실제 브라우저에서 생성하고 18,000장의 프레임과 메모리 사용을 검사한다. `--url`로 다른 로컬 포트를 지정할 수 있다. 검증 결과와 캡처는 Git에서 제외된 `test-results/`에 저장한다.
